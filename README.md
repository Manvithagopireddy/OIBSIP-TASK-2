# Early Personal Portfolio

> OIBSIP Level 1, Task 2 · Learning project

An early personal website exploring profile presentation, social links and navigation.

## Technology

HTML, CSS, Font Awesome

## Project structure

`index.html` — portfolio; `iconss.css` — styles; `whatsapp.html` — contact page.

## Run locally

```bash
git clone https://github.com/Manvithagopireddy/OIBSIP-TASK-2.git
cd OIBSIP-TASK-2
```

Open `index.html` in a modern browser. Alternatively, run `python -m http.server 8000` from the project directory and visit http://localhost:8000.
